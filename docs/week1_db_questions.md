## 6. Решения, принятые мной без согласования (поправьте, если не так)

1. Повторный сбор вакансии обновляет запись в vacancy_raw (UNIQUE source_id + external_id). Старая версия теряется: для учебного проекта допустимо.
2. Пока заведён только источник headhunter. Остальные добавим отдельным файлом.
3. sources.code = headhunter (как в API), не hh.
4. collection_runs приведён к полям API: created, updated, errors, error_message, статус partial.
5. В очереди задач добавится kind = parse_resume.
6. Запрет дублей: applications UNIQUE (user_id, vacancy_id), иначе не будет 409 application_exists.
7. Новый файл резюме заменяет старый (resume_files, PK user_id).
8. Вектор по умолчанию vector(768), меняется до реализации третьей очереди.
9. Расширение vector включено в 00001.
10. Зарплата в базе NULL, если не указана (никогда не 0).

## 7. Замечания к openapi.yaml (результат сверки с базой)

1. Совпадают: User, Me, Profile (все поля и nullable).
2. Вычисляемые, в базе не хранятся: score, explanation, DataQuality, last_success_at.
3. Все nullable-поля Vacancy и Profile помечены верно.
4. Админские адреса отдают 403, остальное 404: согласуется с правилом из описания.

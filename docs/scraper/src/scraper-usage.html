Сборщик вакансий: как пользоваться

Отдельная программа на Go: находит вакансии на hh.ru и Хабр Карьере, разбирает страницы, размечает их сервисом ml (Laya) и отправляет на сервер. Устройство и решения — в docs/scraper-go.md.

01Четыре этапа

Каждый этап читает файл предыдущего и пишет свой, поэтому любой этап можно запустить отдельно или перезапустить после ошибки.

linksОбходит выдачу и собирает только ссылки на вакансии
data/links.json
fetchСкачивает и разбирает страницы; HTML удаляется сразу после разбора
data/vacancies.json
tagТеги, грейд, формат работы от Laya, пакеты по 32
data/vacancies.json
pushОтправляет на сервер только новые и изменённые, пакеты по 100
сервер на хостинге

02Что нужно

  • Go 1.26 — версия из scraper/go.mod. Зависимости скачаются сами при первом запуске.
  • Chrome — только для флага -browser или источников с render: browser.
  • Сервис ml с адресом POST /classify — для этапа tag. Без него вакансии уходят без тегов.
  • Адрес импорта на сервере и токен — для этапа push.

03Первый запуск

Все команды — из папки scraper/. Для проверки достаточно найти ссылки и скачать несколько страниц:

cd scraper
go run ./cmd/scraper links               # найти ссылки
go run ./cmd/scraper fetch -limit 20     # скачать и разобрать 20 страниц

Результат — в data/vacancies.json. В терминал выводятся только числа: найдено, скачано, ошибок. Подробности ошибок — в data/errors.json.

Все этапы подряд

export LAYA_URL=http://localhost:8000          # сервис ml
export PODBOR_URL=https://podbor.example.com    # сервер
export IMPORT_TOKEN=...                         # токен адреса импорта
go run ./cmd/scraper all

05Настройки: sources.yaml

user_agent: "PODBORpro-bot/1.0 (+https://github.com/AlexTihonow/PODBORpro)"
pause: 3s-6s                 # случайная пауза между запросами к одному сайту
max_pages_per_query: 20      # сколько страниц выдачи листать на запрос

sources:
  - code: headhunter
    render: http             # http или browser (Chrome без окна)
    queries:
      - url: "https://hh.ru/vacancies/go-razrabotchik"
  - code: habr
    enabled: true            # false — источник отключён
    queries:
      - url: "https://career.habr.com/vacancies?type=all&sort=date&q=backend"
hh.ru: только адреса без «?». robots.txt hh.ru запрещает ботам любые адреса с параметрами (Disallow: *?*). Обычная выдача /search/vacancy?text=... и листание ?page=1 недоступны, сборщик туда не ходит и пишет в errors.json «адрес запрещён в robots.txt». Для hh.ru указывайте тематические страницы вида https://hh.ru/vacancies/<тема> — на каждой 50 свежих вакансий. Список тем — в картах сайта https://hh.ru/sitemap/vacancies0.xml … vacancies14.xml.

Запросы к другим сайтам — ссылки на выдачу, отсортированную по дате: когда страница выдачи целиком из уже известных ссылок, обход останавливается.

06Папка data/

Всё состояние сборщика. В git не хранится (scraper/data/ в .gitignore).

ФайлЧто в нём
links.jsonСсылки: источник, номер, адрес, когда найдена, когда скачана (fetched_at).
vacancies.jsonРазобранные вакансии; теги Laya; отметки о разметке (tagged_with) и отправке (pushed_hash).
errors.jsonПоследние 2000 ошибок: этап, источник, адрес, причина.
sites.jsonСчётчик блокировок по сайтам и до какого времени сайт пропускается.
html/Скачанные, но ещё не разобранные страницы. Обычно пусто.
html/failed/Страницы, которые не разобрались: по ним видно, что поменялось в вёрстке. Живут 7 дней.
browser_profile/Профиль Chrome для -browser: cookies после пройденной проверки.
Можно прерывать. Ctrl+C, закрытый ноутбук или упавшая программа — не проблема: каждое изменение сразу записывается на диск. Повторный запуск той же командой продолжит с места остановки и не скачает уже скачанное.

07Первый сбор на своей машине

Основную массу вакансий собираем один раз на своём компьютере: это ночь работы, а у Actions лимит времени. С домашнего адреса сайты реже показывают проверку «не робот», а если покажут — вы рядом.

docker compose --profile ml up -d ml     # сервис ml (когда появится /classify)
cd scraper
export LAYA_URL=http://localhost:8000
export PODBOR_URL=https://podbor.example.com
export IMPORT_TOKEN=...
go run ./cmd/scraper all -profile bootstrap -browser
НастройкаОбычный запуск-profile bootstrap
Глубина выдачидо max_pages_per_query, стоп на известных ссылкахвся выдача до конца
Запросыqueriesqueries + bootstrap_queries
Сайтыпо очередипараллельно, по одному потоку на сайт
Проверка «не робот»сбор сайта останавливаетсяс -browser — ждём, пока вы пройдёте её и нажмёте Enter
Отправкав концекаждые 500 вакансий

bootstrap_queries для hh.ru берут из карты сайта все тематические страницы, в адресе которых есть слово из match (razrabotchik, developer, testirov...). Для Хабра запросы дробятся по уровню: split_by: [qid].

Скорость: 700–1000 страниц в час на сайт; 10 000 вакансий с одного сайта — около ночи. Паузы не сокращаем.

Как включить сбор по расписанию

  1. Запустить вручную scrape-access-check (Actions → Run workflow) и убедиться, что страницы скачиваются без блокировок.
  2. Добавить секреты PODBOR_URL и IMPORT_TOKEN (Settings → Secrets and variables → Actions).
  3. Добавить переменную репозитория SCRAPE_ENABLED=true. Без неё расписание не срабатывает, ручной запуск работает всегда.

Запуск красный, только если не собрался ни один сайт или упала отправка. Один заблокированный сайт — запуск зелёный, сайт помечается partial или failed в итоге сбора.

09Если что-то пошло не так

Что видноЧто это значит и что делать
«сбор сайта остановлен» reason=blocked403 или проверка «не робот». Остальные сайты продолжают. Подождать; на своей машине — запустить с -browser. После 3 блокировок подряд сайт пропускается сутки.
reason=rate_limitedСайт ответил 429/503. Сборщик подождал Retry-After (или 10 минут) и остановил сайт. Следующий запуск продолжит.
«адрес запрещён в robots.txt»Запрос из sources.yaml нарушает правила сайта. Заменить на разрешённый адрес (для hh.ru — без «?»).
растёт failed, файлы в html/failed/Сайт поменял вёрстку. Открыть страницу из failed/, поправить разбор в internal/sources/<код>/, затем fetch -retry-failed.
«разметка не удалась, вакансии уйдут без тегов»Сервис ml недоступен. Вакансии отправлены без тегов; теги появятся при следующем запуске.
«не заданы PODBOR_URL и IMPORT_TOKEN»Задать переменные окружения или секреты Actions.
«не собрался ни один сайт», код выхода 1Все сайты заблокированы или пропущены. Посмотреть data/sites.json и data/errors.json.

10Как добавить сайт

  1. Прочитать пользовательское соглашение и robots.txt сайта.
  2. Написать internal/sources/<код>/<код>.go с методами Code, ListLinks, Parse, IsGone. Брать данные по устойчивым атрибутам (data-qa, встроенный JSON страницы), а не по CSS-классам.
  3. Сохранить пару настоящих страниц в testdata/ (gzip -9) и написать тест с эталоном: go test ./... -update создаст JSON, проверьте его глазами.
  4. Добавить строку в registry в cmd/scraper/main.go, источник в sources.yaml и строку в таблицу sources миграцией.

11Правила вежливости

  • Не больше одного запроса одновременно на сайт, пауза 3–6 секунд.
  • robots.txt читается при старте; запрещённые адреса не запрашиваются. Если robots.txt не отвечает (5xx) — к сайту не ходим.
  • Свой User-Agent с адресом проекта, без маскировки под браузер.
  • Проверку «не робот» сборщик не обходит: в Actions сбор сайта останавливается, на своей машине её проходит человек.
  • В логах Actions — только числа: логи публичного репозитория видны всем.
